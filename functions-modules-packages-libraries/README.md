# Objectives

- Functions
- Modules
- Packages
- Libraries

1. Function
<p>A <i>Re-usable</i>  block of code that is intended to perform a specific task/instructions</p>

```py

    def nameOfTheFunction():
        # instructions to be executed.

    # Executing the function
    nameofTheFunction()

```

2. Modules
<p>A module is a <em>Python file </em> that contains a reusable python code.</p>

```tree
  calculation.py

```

3. Packages
<p>A package is a directory organizing a collection of related modules</p>

```tree

functions
|
|-- calculation.py
|
|-- main.py
|
|-- README.md
|
|--- Calculattions
        |-- add.py
        |-- multiply.py

```

4. Library
<p>a collection of pre-written code and packages, modules, functions that you can reuse to perform specific tasks</p>

<p>Is a code that has been created so that other programs or devs can re-use it. </p>
