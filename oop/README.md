# attributes
- Are information that belongs to the object or overal objects.

## class attribute
- These are attributes that belongs to the class. So every instantiated object will access them.
- Attributes shared by all instances(all objects being created.)

## Instance Attribute
- If you want to store different information for diff. instances/objects , we use instance attributes.
- Accessed on the object/instance itself, cannot be accessed by the whole class.

``self`` as also ``this`` in english -- means this particular object being created.


# Properties.
- a special kind of an attribute.
- It let's you control what happens with the attribute.
